# GraphQL - Ejemplo en PHP

Este proyecto implementa un servidor GraphQL básico en PHP utilizando la librería `webonyx/graphql-php`. Permite consultar un saludo personalizado a través de una consulta GraphQL.

## **Requisitos**

- PHP 7.4 o superior
- Composer instalado
